Featured Build

ELEGOO V4 Car Modes

Four planned operating modes for the robot car. The actual features depend on the installed hardware and code.

🚧

Obstacle Mode

Uses a distance sensor to detect obstacles and help the car stop or change direction.

📷

Camera / Wi-Fi Mode

A camera-enabled setup can provide a live view when compatible camera hardware and a connection are available.

〰️

Line Following Mode

Uses line sensors to follow a marked path on a suitable surface.

🎯

Object Following Mode

Uses compatible sensors to detect an object and adjust the car's movement to follow it.
