ELEGOO V4 Multi-Mode Robot Car

My ELEGOO V4 robot car explores autonomous navigation, sensor-based movement and wireless camera control.

Obstacle Avoidance Mode

Uses an ultrasonic sensor to detect obstacles ahead and help the car avoid collisions.

Camera + Wi-Fi Mode

View the camera feed and control the car wirelessly through its compatible Wi-Fi interface.

Line Following Mode

Follows a marked path using the car's line-tracking sensors.

Object Following Mode

Uses supported sensors and programming to detect and follow an object.

Manual Driving Mode

Drive and steer the car using a compatible remote-control interface, if enabled in your setup.
